# 宝石の煌めき ルールまとめ

このメモは、基本セットの「宝石の煌めき / Splendor」を遊ぶための要約です。拡張や「Splendor Duel」は扱いません。

## この実装版でのルール変更

このブラウザ版は、同じPC上でマウスを回して遊ぶローカル対面プレイを想定しています。そのため、実物の「宝石の煌めき」と異なるルールを採用します。

- 山札からの発展カード予約は禁止です。
- 予約できるのは、市場に表向きで公開されている発展カードだけです。
- 予約された発展カードは、すべてのプレイヤーに表向きで公開されます。
- 予約カードは他のプレイヤーには購入されませんが、内容は常に全員が確認できます。

## ゲームの目的

プレイヤーは宝石商となり、宝石トークンを集めて発展カードを購入します。発展カードのボーナスで次の購入を安くし、カードや貴族タイルから威信ポイントを得ます。

誰かが15点以上に到達したラウンドでゲーム終了条件が発生します。最終的に最も威信ポイントが高いプレイヤーが勝利します。

## 内容物

- 宝石トークン5色: 各7枚
  - 白: ダイヤモンド
  - 青: サファイア
  - 緑: エメラルド
  - 赤: ルビー
  - 黒: オニキス
- 黄金トークン: 5枚
  - 支払い時に任意の色として使えるワイルドトークンです。
- 発展カード: 90枚
  - レベル1: 40枚
  - レベル2: 30枚
  - レベル3: 20枚
- 貴族タイル: 10枚
  - 各タイルは3威信ポイントです。

## セットアップ

1. 発展カードをレベルごとに分け、それぞれシャッフルします。
2. レベル1、2、3の山札を並べ、各山札から4枚ずつ表向きに公開します。
3. 貴族タイルをシャッフルし、プレイヤー人数+1枚を表向きに公開します。
   - 2人: 3枚
   - 3人: 4枚
   - 4人: 5枚
4. プレイヤー人数に応じて宝石トークンを用意します。黄金トークンは常に5枚使います。

| 人数 | 各色の宝石トークン | 黄金トークン |
| --- | ---: | ---: |
| 2人 | 各4枚 | 5枚 |
| 3人 | 各5枚 | 5枚 |
| 4人 | 各7枚 | 5枚 |

5. 適当な方法でスタートプレイヤーを決めます。

## 発展カードの見方

- 左上: 威信ポイント
- 右上: 購入後に得られるボーナスの色
- 左下: 購入コスト

購入した発展カードは自分の前に並べます。カード右上のボーナスは、以後その色の宝石1個分として常に数えます。ボーナスは支払いで消費されません。

## 手番でできること

手番では、次の4つから1つを選んで実行します。

### 1. 異なる色の宝石トークンを3枚取る

黄金以外の宝石トークンから、異なる色を3枚取ります。

### 2. 同じ色の宝石トークンを2枚取る

黄金以外の宝石トークンから、同じ色を2枚取ります。

この行動は、取る前にその色のトークンが場に4枚以上残っている場合だけ選べます。

### 3. 発展カードを1枚予約し、黄金トークンを1枚取る

公開されている発展カードから、発展カードを1枚予約します。山札からの予約はできません。

- 予約カードは自分の予約欄に表向きで置きます。
- 予約カードは他のプレイヤーには購入されません。
- 公開カードを予約した場合、同じレベルの山札が残っていれば1枚補充します。
- 黄金トークンが場に残っていれば、1枚取ります。
- 黄金トークンが残っていなくても、カードの予約自体はできます。
- 予約できるカードは最大3枚までです。すでに3枚予約している場合、新たに予約はできません。
- 予約カードを捨てることはできません。手札からなくすには購入する必要があります。

### 4. 発展カードを1枚購入する

公開されている発展カード、または自分が予約している発展カードを1枚購入します。

購入コストは、その色の必要数から自分の発展カードのボーナス数を差し引いて支払います。不足分は宝石トークンで支払い、黄金トークンは任意の色の不足分として使えます。

支払ったトークンは場に戻します。購入したカードはすぐ自分の前に置き、威信ポイントとボーナスはただちに有効になります。公開カードを購入した場合、同じレベルの山札から1枚補充します。

## 手番終了時のトークン上限

手番終了時、自分の持つトークンは合計10枚までです。宝石トークンと黄金トークンの両方を数えます。

10枚を超えている場合は、10枚になるように好きなトークンを場に戻します。

## 貴族タイル

貴族タイルには、訪問条件となる発展カードのボーナス色と枚数が示されています。

手番終了時、自分の発展カードのボーナスが公開されている貴族タイルの条件を満たしていれば、その貴族タイルを獲得します。宝石トークンや黄金トークンは条件に数えません。

- 貴族の獲得に行動や支払いは不要です。
- 複数の貴族条件を同時に満たした場合、その手番で獲得できるのは1枚だけです。
- どの貴族を獲得するかは、条件を満たしたプレイヤーが選びます。
- 貴族タイルの威信ポイントはただちに加算されます。

## ゲーム終了

誰かの威信ポイントが15点以上になったら、そのラウンドの最後のプレイヤーまで手番を行い、全員の手番数をそろえます。

その後、威信ポイントが最も高いプレイヤーが勝利します。

同点の場合は、購入した発展カードの枚数が少ないプレイヤーが勝利します。貴族タイルはこの枚数に含めません。それでも同点なら同点勝利です。

## よくある確認

- 黄金トークンは、予約したカード以外の購入にも使えます。
- 宝石トークンを取った直後に10枚を超えてもかまいません。手番終了時に10枚以下なら問題ありません。
- 発展カードのボーナスは割引として使うだけで、なくなりません。
- 山札が尽きたレベルでは、公開カードを補充できません。その場合は空いたまま続けます。
- このブラウザ版では、予約カードの内容は全員が確認できます。
