# 宝石の煌めき ルールまとめ

このメモは、基本セットの「宝石の煌めき / Splendor」を遊ぶための要約です。拡張や「Splendor Duel」は扱いません。

## この実装版でのルール変更

このブラウザ版は、同じPC上でマウスを回して遊ぶローカル対面プレイを想定しています。そのため、実物の「宝石の煌めき」と異なるルールを採用します。

- 山札からの発展カード予約は禁止です。
- 予約できるのは、ギルドに表向きで公開されている発展カードだけです。
- 予約された発展カードは、すべてのプレイヤーに表向きで公開されます。
- 予約カードは他のプレイヤーには購入されませんが、内容は常に全員が確認できます。
- 手番順はゲーム開始時にランダムにシャッフルします。
- 合法手がない場合は、手番をパスして次のプレイヤーに進みます。

## ゲームの目的

プレイヤーは宝石商となり、宝石マナを集めて発展カードを購入します。発展カードの兵で次の購入を安くし、カードや紋章タイルから威信ポイントを得ます。

誰かが15点以上に到達したラウンドでゲーム終了条件が発生します。最終的に最も威信ポイントが高いプレイヤーが勝利します。

## 内容物

- 通常マナ5種類: 各7枚
  - 光
  - 雷
  - 精
  - 炎
  - 闇
- 全マナ: 5枚
  - 支払い時に任意の種類として使えるワイルドマナです。
- 発展カード: 90枚
  - レベル1: 40枚
  - レベル2: 30枚
  - レベル3: 20枚
- 紋章タイル: 10枚
  - 各タイルは3威信ポイントです。

## セットアップ

1. 発展カードをレベルごとに分け、それぞれシャッフルします。
2. レベル1、2、3の山札を並べ、各山札から4枚ずつ表向きに公開します。
3. 紋章タイルをシャッフルし、プレイヤー人数+1枚を表向きに公開します。
   - 2人: 3枚
   - 3人: 4枚
   - 4人: 5枚
4. プレイヤー人数に応じて宝石マナを用意します。全マナは常に5枚使います。

| 人数 | 各通常マナ | 全マナ |
| --- | ---: | ---: |
| 2人 | 各4枚 | 5枚 |
| 3人 | 各5枚 | 5枚 |
| 4人 | 各7枚 | 5枚 |

5. このブラウザ版では、プレイヤー全員の手番順をランダムにシャッフルします。

## 発展カードの見方

- 左上: 威信ポイント
- 右上: 購入後に得られる兵の種類
- 左下: 購入コスト

購入した発展カードは自分の前に並べます。カード右上の兵は、以後その種類の通常マナ1個分として常に数えます。兵は支払いで消費されません。

## 手番でできること

手番では、次の4つから1つを選んで実行します。

このブラウザ版では、購入・予約・マナ取得のいずれもできない場合だけ、手番をパスします。

### 1. 異なる種類の通常マナを3枚取る

全以外の通常マナから、異なる種類を3枚取ります。

### 2. 同じ種類の通常マナを2枚取る

全以外の通常マナから、同じ種類を2枚取ります。

この行動は、取る前にその種類のマナが場に4枚以上残っている場合だけ選べます。

### 3. 発展カードを1枚予約し、全マナを1枚取る

公開されている発展カードから、発展カードを1枚予約します。山札からの予約はできません。

- 予約カードは自分の予約欄に表向きで置きます。
- 予約カードは他のプレイヤーには購入されません。
- 公開カードを予約した場合、同じレベルの山札が残っていれば1枚補充します。
- 全マナが場に残っていれば、1枚取ります。
- 全マナが残っていなくても、カードの予約自体はできます。
- 予約できるカードは最大3枚までです。すでに3枚予約している場合、新たに予約はできません。
- 予約カードを捨てることはできません。手札からなくすには購入する必要があります。

### 4. 発展カードを1枚購入する

公開されている発展カード、または自分が予約している発展カードを1枚購入します。

購入コストは、その種類の必要数から自分の発展カードの兵数を差し引いて支払います。不足分は通常マナで支払い、全マナは任意の種類の不足分として使えます。

支払ったマナは場に戻します。購入したカードはすぐ自分の前に置き、威信ポイントと兵はただちに有効になります。公開カードを購入した場合、同じレベルの山札から1枚補充します。

## 手番終了時のマナ上限

手番終了時、自分の持つマナは合計10枚までです。宝石マナと全マナの両方を数えます。

10枚を超えている場合は、10枚になるように好きなマナを場に戻します。

## 紋章タイル

紋章タイルには、訪問条件となる発展カードの兵種類と枚数が示されています。

手番終了時、自分の発展カードの兵が公開されている紋章タイルの条件を満たしていれば、その紋章タイルを獲得します。宝石マナや全マナは条件に数えません。

- 紋章の獲得に行動や支払いは不要です。
- 複数の紋章条件を同時に満たした場合、その手番で獲得できるのは1枚だけです。
- どの紋章を獲得するかは、条件を満たしたプレイヤーが選びます。
- 紋章タイルの威信ポイントはただちに加算されます。

## ゲーム終了

誰かの威信ポイントが15点以上になったら、そのラウンドの最後のプレイヤーまで手番を行い、全員の手番数をそろえます。

その後、威信ポイントが最も高いプレイヤーが勝利します。

同点の場合は、購入した発展カードの枚数が少ないプレイヤーが勝利します。紋章タイルはこの枚数に含めません。それでも同点なら同点勝利です。

## よくある確認

- 全マナは、予約したカード以外の購入にも使えます。
- 宝石マナを取った直後に10枚を超えてもかまいません。手番終了時に10枚以下なら問題ありません。
- 発展カードの兵は割引として使うだけで、なくなりません。
- 山札が尽きたレベルでは、公開カードを補充できません。その場合は空いたまま続けます。
- このブラウザ版では、予約カードの内容は全員が確認できます。
