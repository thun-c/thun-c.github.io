# 人数別・紋章覚醒セット v1 追加調整

実施日: 2026-06-05

## 目的

人数別の紋章覚醒セット v1 実装後、3人戦で紋章あり勝者がまだ多かったため、3人戦の覚醒プールを追加調整した。
紋章あり/なしの勝者比率だけでなく、手番順の勝率も確認した。

## 試した3人戦プール

### 候補A: `単醒, 王庫, 補給, 補給`

通常LV04 150戦。

| 指標 | 結果 |
|---|---:|
| 打ち切り | 0 |
| 無紋章勝者 | 27.333% |
| 紋章あり勝者 | 72.667% |
| 無紋章トリガー | 33.333% |
| 紋章ありトリガー | 66.667% |
| 1番手勝率 | 37.667% |
| 2番手勝率 | 35.667% |
| 3番手勝率 | 26.667% |

まだ紋章あり勝者が多く、3番手も低め。

### 候補B: `王庫, 補給, 補給, 補給`

通常LV04 150戦を2セット、合計300戦。

| 指標 | 150戦目 | 追加150戦 | 合算 |
|---|---:|---:|---:|
| 打ち切り | 0 | 0 | 0 |
| 無紋章勝者 | 37.333% | 32.333% | 34.833% |
| 紋章あり勝者 | 62.667% | 67.667% | 65.167% |
| 無紋章トリガー | 47.333% | 43.333% | 45.333% |
| 紋章ありトリガー | 52.667% | 56.667% | 54.667% |
| 1番手勝率 | 34.667% | 29.333% | 32.000% |
| 2番手勝率 | 24.333% | 38.333% | 31.333% |
| 3番手勝率 | 41.000% | 32.333% | 36.667% |

紋章あり勝者はまだ多いが、候補Aより改善。
手番順はセットごとに偏りの向きが変わり、合算では大きな問題は見えなかった。

ルート固定スモーク 120戦。

| 指標 | 結果 |
|---|---:|
| 打ち切り | 0 |
| 紋章AI勝者 | 80.833% |
| 無紋章AI勝者 | 19.167% |
| 実際の無紋章勝者 | 46.667% |

| 1番手勝率 | 40.000% |
| 2番手勝率 | 26.667% |

ルート固定では紋章AIが依然強い。
ただし、実際の紋章あり/なし勝者では比較的近く、紋章AIが紋章獲得前に13点で勝つ展開も含まれる。

候補Bより悪化したため不採用。

## 採用

3人戦は候補Bの `王庫, 補給, 補給, 補給` を採用する。

現時点の人数別プール:

| 人数 | 覚醒プール |
|---|---|
| 2人 | `双醒`, `双醒`, `補給` |
| 3人 | `王庫`, `補給`, `補給`, `補給` |
| 4人 | `双醒`, `双醒`, `単醒`, `王庫`, `補給` |

## 考察

3人戦は、覚醒トークンを抜いても紋章あり勝者がまだ多い。
これは覚醒効果だけでなく、紋章そのものの3点と、紋章あり15点終了の構造が3人戦で強い可能性が高い。

一方で、手番順は300戦合算では大きな崩れは見えなかった。
候補Bでは、1番手32.0%、2番手31.3%、3番手36.7%で、許容範囲に見える。

次に3人戦をさらに寄せるなら、覚醒配分だけではなく、無紋章終了点12点など別軸の調整も検討する価値がある。
